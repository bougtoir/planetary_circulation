# FIG3 LABEL-OVERLAP FIX REPORT — minimal cosmetic correction

## Original overlap
In `fig3_ordination.png` (exploratory PCA, n=8), the "Mars" and "Io" labels
collided at bottom-right: points Mars (PC1≈1.0, PC2≈−1.6) and Io (≈1.5,−1.55)
are ~0.5 apart on PC1, and both labels used the same offset (+6,+4 pt), so
"Mars" ran into Io's marker/label.

## Exact code change
File: `analysis/scripts/analyze.py`, Fig-3 block (lines ~95–100).
Before: single `ax.annotate(b, ..., xytext=(6,4))` for every body.
After: per-label offset + alignment dicts —
```python
LABOFF={"Io":(8,-8),"Mars":(-8,-3)}
LABHA={"Mars":"right"}
for b in scores.index:
    ax.annotate(b,(scores.loc[b,"PC1"],scores.loc[b,"PC2"]),
                textcoords="offset points",xytext=LABOFF.get(b,(6,4)),
                ha=LABHA.get(b,"left"),fontsize=9)
```
Mars label now sits left of its point (right-aligned); Io sits right-below.
All other bodies keep the original (6,4) offset. No leader line needed.

## Placement method
Deterministic per-label `offset points` overrides for exactly two labels;
no recomputation of PCA, no coordinate/axis/legend/style change, same
figsize 5.2×4.4, fontsize 9, dpi 300, colors.
